# 基于 SpringBoot + Vue 的电脑维修服务系统 (Computer Repair Service System)

电脑报修 · 智能派单 · 工单流转 · 支付宝缴费 · 备件管理 · 维修评价 · 数据统计

本项目是一套面向电脑维修服务与产品售后服务场景的工单管理系统，覆盖“客户报修、预约上门、工单派单、维修执行、备件更换、支付宝缴费、服务评价、数据统计”等核心业务。系统分为管理员、客户、维修员三类角色：管理员负责用户、员工、工单、维修信息、产品信息、预约、缴费记录、评价与公告管理；客户可注册登录、提交报修、查看工单进度、完成支付宝工单缴费并评价服务；维修员可接收任务、查看任务日历、更新维修进度、记录备件使用与维修结果。

## 核心特性

- **客户自助报修**：客户可通过邮箱注册账号，提交电脑故障报修信息，填写设备型号、故障描述、预约时间与联系方式。
- **预约管理**：支持客户选择上门服务时间，管理员或系统根据维修员排班、服务区域与技能进行预约确认。
- **工单全流程管理**：工单覆盖待受理、已派单、待上门、维修中、待缴费、已完成、已评价等状态，支持全过程追踪。
- **维修信息记录**：维修员可在工单中记录故障原因、处理方案、更换配件、维修时长、现场照片与客户确认信息。
- **产品与备件管理**：管理员维护产品信息、备件信息与库存，维修员在维修过程中关联使用备件并自动扣减库存。
- **支付宝工单缴费**：客户完成维修后可通过支付宝缴纳维修费、配件费与服务费，系统同步更新缴费记录与工单状态。
- **服务评价管理**：客户可对已完成工单进行评分与文字评价，管理员可查看评价数据并用于服务质量分析。
- **任务日历**：维修员可通过任务日历查看每日、每周维修任务安排，直观掌握上门时间与服务进度。
- **公告信息发布**：管理员发布服务通知、营业时间调整、优惠活动与系统公告，客户可在前台查看。
- **数据统计看板**：统计工单数量、维修完成率、平均响应时长、热门故障类型、维修员绩效、缴费金额与客户满意度。

## 功能模块概览

### 管理员端

- **用户管理**：管理客户账号、联系方式、邮箱、地址、账号状态与历史报修记录。
- **员工管理**：管理维修员账号、姓名、技能标签、服务区域、在岗状态与绩效信息。
- **评价管理**：查看客户对工单的服务评价，支持筛选、回复、隐藏与异常评价处理。
- **服务类型**：维护电脑维修服务类型，如系统重装、硬件维修、屏幕更换、数据恢复、网络调试等。
- **预约管理**：查看客户预约信息，确认上门时间，分配维修员，并处理改约与取消。
- **维修信息**：查看工单对应的故障描述、检测结果、维修方案、更换配件与维修结果。
- **产品信息**：维护电脑品牌、型号、配置、保修信息与备件产品库。
- **缴费记录**：查看客户工单缴费记录，包括缴费金额、支付方式、缴费时间与订单状态。
- **工单管理**：创建、分配、跟踪与关闭工单，支持按状态、客户、维修员与时间筛选。
- **公告信息**：发布服务公告、优惠活动、营业时间调整与系统通知。

### 客户端

- **我的工单**：查看本人提交的报修工单，跟踪待受理、维修中、待缴费、已完成等状态。
- **个人信息**：维护姓名、手机号、邮箱、收货地址、设备信息与常用服务偏好。
- **缴费记录**：查看历史缴费明细，包括工单编号、缴费金额、缴费时间与支付状态。
- **维修信息**：查看工单维修详情，包括故障原因、处理方案、更换配件与维修完成时间。
- **支付宝工单缴费**：对已完成维修的工单进行在线缴费，支持查看费用明细并完成支付。
- **邮箱注册**：通过邮箱注册账号，完成邮箱验证后登录系统提交报修与查看工单。

### 维修员端

- **我的任务**：查看已分配的维修任务，包括客户信息、设备故障、预约时间、服务地址与工单状态。
- **任务日历**：以日历形式查看每日、每周维修任务安排，支持按日期筛选与状态标记。
- **维修记录**：更新维修进度，记录故障检测结果、处理方案、使用配件、维修照片与客户确认信息。
- **工单反馈**：提交维修完成反馈，等待客户验收、缴费与评价。
